Objective

Build and evaluate supervised classification models to estimate whether a customer will churn. The target column is Churn (Yes = 1, No = 0). CustomerID is excluded from model training because it is an identifier.

Methodology

  1. Numeric features: median imputation and MinMax scaling.
  2. Categorical features: most-frequent imputation and One-Hot Encoding.
  3. 80/20 stratified train-test split with random_state=42.
  4. Train Logistic Regression and Random Forest classifiers.
  5. Evaluate Precision, Recall, F1-score, Accuracy and ROC-AUC.
  6. Export customer churn probabilities and Low/Medium/High risk bands.

Limitations

The dataset is synthetic. Evaluation uses one random split. Before real-world use, validate on newer unseen data, check calibration and subgroup performance, and select a threshold based on business costs.
